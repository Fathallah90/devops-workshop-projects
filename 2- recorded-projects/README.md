
# Recorded Projects

## Overview

This section contains eight recorded-project exercises focused on infrastructure automation, cloud migration, configuration management, Kubernetes operations, infrastructure provisioning, CI/CD, and GitOps.

These projects reinforce the workshop concepts through practical implementation and provide an opportunity to improve automation, troubleshooting, and deployment skills.

## Technologies Covered

- Bash and shell scripting
- Zabbix monitoring
- AWS EC2 and Route 53
- Ansible and AWX
- Kubernetes and Helm
- Monitoring and telemetry
- Terraform and Infrastructure as Code
- Jenkins and GitHub Actions
- Argo CD and GitOps

## Learning Objectives

- Automate repetitive infrastructure tasks.
- Provision cloud resources consistently.
- Deploy and manage applications on Kubernetes.
- Implement monitoring and observability.
- Build repeatable CI/CD workflows.
- Practice GitOps-based deployment management.

## Documentation Standards

Each project will document its objectives, prerequisites, architecture, implementation, configuration, testing, troubleshooting, and cleanup procedures where applicable.
