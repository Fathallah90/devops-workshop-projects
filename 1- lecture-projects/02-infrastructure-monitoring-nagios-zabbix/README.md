# Project 02 – Infrastructure Monitoring with Nagios and Zabbix

## Project Overview

This project focuses on infrastructure monitoring using two open-source monitoring solutions: **Nagios** and **Zabbix**.

The goal is to monitor server availability, system performance, network connectivity, and service health through centralized monitoring platforms.

## Technologies Used

- Nagios Core
- Zabbix
- Linux
- PostgreSQL
- Nginx
- Zabbix Agent
- Nagios Plugins

## Monitoring Capabilities

- Server availability and uptime.
- CPU and memory utilization.
- Disk space monitoring.
- Network connectivity.
- Service availability.
- Performance monitoring.
- Alerts and notifications.

## Project Objectives

- Implement centralized infrastructure monitoring.
- Monitor Linux servers and critical services.
- Configure monitoring agents and plugins.
- Create monitoring dashboards.
- Configure alerts and notifications.
- Identify and troubleshoot infrastructure issues.
- Improve infrastructure visibility and availability.

## Validation and Testing

- Verify host availability.
- Monitor system resource utilization.
- Test network and service connectivity.
- Simulate service failures.
- Verify alert generation and recovery.

## Skills Demonstrated

- Linux System Administration.
- Infrastructure Monitoring.
- Nagios Administration.
- Zabbix Administration.
- Monitoring and Alerting.
- System Troubleshooting.
- Infrastructure Operations.

## Conclusion

This project demonstrates practical experience in implementing infrastructure monitoring solutions using Nagios and Zabbix.

It provides hands-on experience in monitoring infrastructure health, identifying service failures, analyzing system performance, and maintaining service availability.
