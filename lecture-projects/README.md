# Lecture Projects

## Overview

This section contains nine hands-on projects from the DevOps workshop, covering enterprise infrastructure, application deployment, monitoring, automation, containerization, cloud infrastructure, CI/CD, and service mesh technologies.

The objective is to build practical DevOps skills by implementing and documenting real-world infrastructure and application deployment scenarios.

## Technologies Covered

- Linux and enterprise infrastructure
- Java web application deployment
- Nagios and Zabbix monitoring
- AWS cloud services
- Ansible and AWX automation
- Docker containerization
- Kubernetes and OpenShift
- Terraform Infrastructure as Code
- Jenkins, GitHub Actions and Argo CD
- Service mesh architecture

## Documentation Standards

Each project will include relevant documentation, architecture diagrams, prerequisites, implementation steps, configuration files, validation results, troubleshooting notes, and lessons learned.

## Progress

Projects will be updated as implementation progresses. A project is marked **Completed** after its implementation has been tested and documented.
